# Changelog

## 0.1.0
- Initial release: universal `document_loader` for text, PDF, Word, Excel,
  PowerPoint, CSV/TSV, JSON, XML, YAML, HTML, RTF, EPUB, EML, images (OCR),
  audio (transcription), video (frame OCR) and source-code files.
- `load`, `load_many`, `load_directory`, `supported_formats`.
